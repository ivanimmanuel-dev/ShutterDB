# Contributing

Report bugs with reproducing code or commands, the ShutterDB version, compiler, OS
and filesystem. For features, describe the application problem and proposed behavior.
Report vulnerabilities [privately](SECURITY.md).

## Code changes

Use clang-format 21. Run the [tests](docs/testing.md) for the changed component;
include a regression test for a bug fix and update affected API documentation.
For performance changes, include the workload, build settings and raw measurements.

Pull requests should explain the resulting behavior and test results.
