# ShutterDB v0.2.0

Persistent binary caches for C++20.

## Changes

- `shutter::Cache`: LRU eviction, automatic compaction and hit/miss statistics. The
  default budget for the main file is 1 GiB; call `sync()` to synchronize buffered writes.
- Buffered log scanning: a reusable read window and index updates in place reduce
  reads and allocations during opening and verification.
- Runtime-detected x86-64 CRC32C acceleration, a portable fallback and one-buffer
  indexed reads.
- PNG/JPEG preview caching with transparency and content-hash reuse across filenames
  and process restarts.
- SQLite and RocksDB benchmarks covering ingestion, reads, updates and compaction
  on 64 MiB and 1 GiB datasets.

## Upgrade

Format v1 is unchanged; existing databases need no migration. `DB` keeps synchronous
writes by default. `Cache` uses the same format and evicts entries to meet its budget.

The core library and CLI build without third-party dependencies. The optional image example
requires OpenSSL, libpng 1.6+ and libjpeg.
