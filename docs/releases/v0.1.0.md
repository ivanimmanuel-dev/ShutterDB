# ShutterDB v0.1.0 — experimental

A small C++20 embedded key-value engine with checksummed append-only storage,
sync-by-default writes, explicit tail recovery, manual compaction and a practical CLI.
MIT licensed; no third-party runtime dependency. The on-disk format is v1.

This release hardens the existing engine without adding roadmap features. It fixes
unsupported-format backup rollback, FIFO inspection hangs, and invalid sequence handling
in partial tails. Verification now reports incomplete-tail offsets consistently in JSON.

Validation includes hosted Linux GCC/Clang Debug/Release, Windows MSVC Debug/Release,
macOS, ASan, UBSan, formatting/static analysis, independent installed/FetchContent
consumers, a million-operation oracle workload, 28 corruption scenarios, 24 Linux syscall
failure scenarios and deterministic abrupt-process tests. Timed ASan/UBSan fuzz campaigns,
memory measurements and reproducible benchmark results are recorded in the
[validation report](https://github.com/ivanimmanuel-dev/ShutterDB/blob/v0.1.0/docs/validation.md).

Downloads include source and hosted Linux/Windows x64 packages, SHA-256 sums and
commit/file manifests. Build with the README's three CMake commands; default source
builds require no network access. Binary packages require compatible system runtimes.

**Experimental means keep backups.** These results do not establish physical power-loss
safety, protection from sector tearing or reordered writes, production suitability, or
indefinite API/format compatibility. An errored write may be present after reopening.
Windows and macOS flush semantics differ from Linux; read the
[durability contract](https://github.com/ivanimmanuel-dev/ShutterDB/blob/v0.1.0/docs/durability.md).
No known serious release blocker remains within the tested scope. No v0.2 work is included.
