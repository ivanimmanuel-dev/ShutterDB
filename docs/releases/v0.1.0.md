# ShutterDB v0.1.0

The first experimental release of ShutterDB: embedded key-value storage for C++20,
with checksummed append-only files, synchronous writes, recovery and manual compaction.
MIT licensed. On-disk format v1.

## Included

- Binary keys and values, tombstones and an in-memory key index.
- Sync-by-default writes, optional buffering and explicit synchronization.
- CLI for text and binary I/O, JSON diagnostics, verification and recovery.
- Static library with CMake install/export and FetchContent support.
- Source and Linux/Windows x64 packages, SHA-256 sums and file manifests.

## Fixes

- Preserve an unsupported-format primary when a compaction backup exists.
- Reject FIFO inspection without blocking.
- Reject out-of-order sequences in incomplete final records.
- Include incomplete-tail categories and offsets in JSON verification output.

## Validation

All 12 [CI jobs](https://github.com/ivanimmanuel-dev/ShutterDB/actions/runs/37281939602)
passed on commit `4e7f884a3dbabfa429ba9d7a08be159d28323f98`, including Linux GCC/Clang,
Windows MSVC, macOS, ASan, UBSan and package consumers.

- 1,000,000 mixed operations across 100,000 keys.
- 8,878,774 local fuzz executions, with no crashes or sanitizer findings.
- 28 corruption cases and 24 Linux syscall-failure scenarios.
- Identical source archives produced on Linux and Windows.

The [release workflow](https://github.com/ivanimmanuel-dev/ShutterDB/actions/runs/37282305611)
built, tested and published both native packages. Downloaded packages passed CLI and
relocated CMake consumer checks. Full measurements are in the
[validation report](https://github.com/ivanimmanuel-dev/ShutterDB/blob/main/docs/validation.md).

See [durability](https://github.com/ivanimmanuel-dev/ShutterDB/blob/main/docs/durability.md)
for synchronization, recovery and filesystem requirements.
