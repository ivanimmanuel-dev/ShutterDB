# ShutterDB v0.1.0

Embedded key-value storage for C++20,
with checksummed append-only files, synchronous writes, recovery and manual compaction.
MIT licensed. On-disk format v1.

## Included

- Binary keys and values, tombstones and an in-memory key index.
- Sync-by-default writes, optional buffering and explicit synchronization.
- CLI for text and binary I/O, JSON diagnostics, verification and recovery.
- Static library with CMake install/export and FetchContent support.
- Source and Linux/Windows x64 packages, SHA-256 sums and file manifests.

## Fixes

- Preserve an unsupported-format primary when a compaction backup exists.
- Reject FIFO inspection without blocking.
- Reject out-of-order sequences in incomplete final records.
- Include incomplete-tail categories and offsets in JSON verification output.

See [durability](https://github.com/ivanimmanuel-dev/ShutterDB/blob/v0.1.0/docs/durability.md)
for synchronization, recovery and filesystem requirements.
